Abstract

Optical coherence tomography (OCT) provides volumetric feedback for controlling soft-tissue deformation. We study target-conditioned robot policies learned from operator demonstrations using three OCT representations: full volumes, tissue-masked sparse volumes, and voxelized point clouds. Each representation is evaluated with and without residual conditioning, using Explicit and Diffusion action prediction.

Across twelve configurations and 576 phantom rollouts, performance depends on both representation and residual conditioning. Point-cloud Explicit with residuals achieves final Shape RMSE of 0.534 mm for depth control and 0.443 mm for directional control, with comparable accuracy at intermediate, unseen targets. Sixty ex vivo porcine rollouts extend the evaluation to biological tissue, where local target alignment and mismatch in the surrounding geometry can coexist.

Installation and verification

Download the Python wheel and small dataset into the same directory, then run:

Python 3.10 or newer 
python -m pip install ./oct_tissue_policy-0.1.0-py3-none-any.whl
tar -xzf mini-point-cloud.tar.gz

oct-policy smoke \
  --prepared mini_prepared_public_candidate_v2 \
  --experiment phantom_point_cloud_with_residual_bc \
  --verify-all-cache-files \
  --device cpu

This checks cache integrity and model input/output contracts with a randomly initialized policy. It is not an evaluation of a trained checkpoint. Training and checkpoint evaluation commands are included in the source documentation.
